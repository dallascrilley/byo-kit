
## Actual page inspection

For user-visible work, follow `project-journey-proof`. Exercise the real page, then actually inspect it visually or open current screenshots with an image-capable tool. Include affected desktop/mobile views and relevant empty, loaded and error states. Fix visible defects and repeat the affected checks.

A text-only agent obtains an image-capable review or reports visual review incomplete. Capture, DOM checks, computed styles and passing tests alone do not establish that anyone looked. Record the reviewer, source/build, target, inspected views and findings in the existing proof record. Inspect the deployed page before claiming live UI delivery.
